# Contributing

Infra is in public alpha. Bug reports, security reports, reproducible test cases, and integration feedback are welcome.

External code contributions are not accepted during this alpha unless the maintainer has agreed to the contribution and its license in writing before submission. This temporary rule avoids ambiguous ownership across the repository's MIT and PolyForm Shield scopes.

- Use GitHub issues for reproducible bugs and product feedback.
- Use private vulnerability reporting for security issues.
- Do not include customer data, credentials, private trajectories, or confidential evidence.
- Do not submit managed-refinery implementations or private operational material.

This policy may be replaced by a contributor license agreement or developer certificate of origin after the public boundary is proven in real use.
